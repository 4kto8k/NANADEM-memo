# 나나덤 홀덤 기록표

보드게임 모임 홀덤 딜러용 하루 기록표 (모바일 웹앱).

- 블라인드 업 알림: 오락실 레벨업 소리(블라인드 구조 메뉴에서 미리 듣기), 아이폰 무음 스위치를 켜 둬도 재생(최신 iOS)
- 블라인드 타이머: 20레벨(2,000/4,000 뒤 10분 휴식), 3,000/6,000 끝나면 리바인 마감 공지
- 레벨 시간: 시작 10분, 탈락 입력 시 단축(기본 8등 7분+블라인드 업, 7등 6분, 6등 6분, 5등부터 5분). 블라인드 구조 메뉴에서 바꿀 수 있음, 바뀔 때 확인 창
- 게임 중 남은 시간 조절(−1분, −10초, +10초, +1분, 직접 입력)
- 게임 시작/종료 시간 기록
- 자리별 이름, 미션번호, 등수, 뽑기점수 입력
- 당일총점 자동 계산: 참가 기본 1점 + 등수 보너스(1등 +4, 2등 +2, 3·4등 +1) + 딜러(4번 자리) +0.5 + 뽑기점수
- 결과 복사: 카톡에 붙여넣을 수 있는 등수순 결과
- 결과 저장: 딜러 비밀번호를 넣으면 온라인(Supabase)에 저장되고 월간 랭킹에 쌓임 (`#ranking` 화면)
- 입력 중인 기록은 각자 폰 브라우저에 저장되고, "결과 저장"을 눌러야 랭킹에 올라감

수정하려면 `index.html` 하나만 고치면 됩니다.
