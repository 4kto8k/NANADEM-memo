# 나나덤 홀덤 기록표

보드게임 모임 홀덤 딜러용 하루 기록표 (모바일 웹앱).

- 블라인드 업 알림: 오락실 레벨업 소리, 리바인 마감: 복싱 종 땡땡땡(레벨업 소리 뒤). 블라인드 구조 메뉴에서 미리 듣기, 아이폰 무음 스위치를 켜 둬도 재생(최신 iOS)
- 블라인드 타이머: 20레벨(2,000/4,000 뒤 10분 휴식), 3,000/6,000 끝나면 리바인 마감 공지
- 레벨 시간: 시작 10분, 탈락 입력 시 단축(기본 8등 7분+블라인드 업, 7등 6분, 6등 6분, 5등부터 5분). 블라인드 구조 메뉴에서 바꿀 수 있음, 바뀔 때 확인 창
- 게임 중 남은 시간 조절(−1분, −10초, +10초, +1분, 직접 입력)
- 게임 시작/종료 시간 기록
- 자리별 이름, 미션번호, 등수, 뽑기점수 입력
- 당일총점 자동 계산: 참가 기본 1점 + 등수 보너스(1등 +4, 2등 +2, 3·4등 +1) + 딜러(4번 자리) +0.5 + 뽑기점수
- 결과 복사: 카톡에 붙여넣을 수 있는 등수순 결과
- 결과 저장: 딜러 비밀번호를 넣으면 온라인(Supabase)에 저장되고 월간 랭킹에 쌓임 (`#ranking` 화면)
- 입력 중인 기록은 각자 폰 브라우저에 저장되고, "결과 저장"을 눌러야 랭킹에 올라감

- 리바인: 리바인 기간에 등수를 넣으면 리바인/탈락 확정을 물어봄. 자리 번호를 누르면 리바인 횟수 수정

## 여러 테이블 토너먼트 (`#tourney`)

일회성이며 월간 랭킹에 들어가지 않습니다.

- 블라인드 타이머 하나를 모든 테이블 폰이 함께 봄(서버 시각 기준). 타이머와 토너 세팅은 토너먼트를 만든 폰(방장)만 조작, "1번 테이블(이름) 일시정지" 같은 알림
- 방장 폰이 꺼졌거나 방장이 정리를 안 하면: "여러 테이블" 화면 맨 아래 **관리자** 메뉴(관리자 비밀번호, 딜러 비밀번호와 별도)에서 방장 맡기 · 강제 종료 · 삭제 · 끝났거나 지난 토너먼트 한 번에 정리
- 참가자 등록 → 시작 자리 뽑기(테이블마다 정한 딜러는 4번 고정) → 토너먼트 시작
- 자리마다 탈락 / 이동(빈자리 랜덤) / 리바인·이름 수정, 탈락은 언제든 되돌리기 가능(등수 자동 재계산)
- 리바인 기간 탈락은 리바인 또는 탈락 확정을 고름
- 남은 인원·테이블별 인원 표시, 2명 이상 차이 나면 이동 추천
- 파이널 테이블 인원(기본 8명)이 되면 타이머 정지 → 파이널 테이블 자리 랜덤 뽑기(4번 딜러 규칙 없음)
- 마지막 1명이 남으면 자동 우승, 최종 순위 복사
- 토너 세팅(파이널 인원, 테이블당 자리, 블라인드, 레벨 시간)은 시작 전·일시정지 중에만 바꿈

## 홈 화면 앱

- `manifest.webmanifest` + `icons/`: 홈 화면에 추가하면 주소창 없이 "나나덤" 앱처럼 열림
- 카톡 등 앱 안 브라우저로 열면 크롬/사파리로 열기 안내를 띄움 (앱 안 브라우저는 주소창을 숨길 수 없고 저장 공간도 따로)

수정하려면 `index.html` 하나만 고치면 됩니다.
