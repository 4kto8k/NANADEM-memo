# 나나덤 홀덤 기록표

보드게임 모임 홀덤 딜러용 하루 기록표 (모바일 웹앱).

- 소리 설정 창(🔊): 전체 켜기/끄기, 알림별 사용 체크(블라인드 업·리바인 마감·1분 전·새로 온 사람), 들어보기, 블라인드 업 소리 고르기(징(기본) · 징+심벌즈 · 오락실(예전 소리)). 징 소리는 실제 녹음 효과음 `sounds/gong.mp3`, `sounds/gong-cymbal.mp3` (freesound.org CC0. 징: #112507 cdiupe, 징+심벌즈: #121800 BOSS MUSIC + #104217 minorr. 잘라서 음량 맞춤), 서비스 워커가 미리 저장해 인터넷이 없어도 재생, 아이폰 무음 스위치를 켜 둬도 재생(최신 iOS)
- 블라인드 타이머: 20레벨(2,000/4,000 뒤 10분 휴식), 3,000/6,000 끝나면 리바인 마감 공지
- 레벨 시간: 시작 10분, 탈락 입력 시 단축. 몇 번째 탈락인지로 정함. 7~8명: 첫 탈락 7분+블라인드 업, 2번째 6분, 3번째 6분, 4번째부터 5분. 6명 이하: 첫 탈락 6분+블라인드 업, 2번째부터 5분 (인원 = 이름 등이 적힌 자리 수). 블라인드 구조 메뉴에서 바꿀 수 있음, 바뀔 때 확인 창
- 🎲 자리 랜덤 뽑기(게임 시작 전, 4번 딜러 이름과 플레이어 2명 이상일 때): 4번은 그대로, 나머지는 앞자리부터 빈틈없이 섞음(6명이면 1·2·3·5·6번). 결과 창에서 다시 뽑기, 10초 되돌리기
- 같은 멤버로 새 게임: 이름(과 테이블 이름)만 남기고 미션번호·등수·뽑기점수·타이머는 새로(두 번 눌러야 함)
- 게임 중 남은 시간 조절(−1분, −10초, +10초, +1분, 직접 입력)
- 게임 시작/종료 시간 기록
- 자리별 이름, 미션번호, 등수, 뽑기점수 입력
- 당일총점 자동 계산: 참가 기본 1점 + 등수 보너스(1등 +4, 2등 +2, 3·4등 +1) + 딜러(4번 자리) +0.5 + 뽑기점수
- 결과 복사: 카톡에 붙여넣을 수 있는 등수순 결과
- 결과 저장: 딜러 비밀번호를 넣으면 온라인(Supabase)에 저장되고 월간 랭킹에 쌓임 (`#ranking` 화면)
- 입력 중인 기록은 각자 폰 브라우저에 저장되고, "결과 저장"을 눌러야 랭킹에 올라감

- 리바인: 리바인 기간에 등수를 넣으면 리바인/탈락 확정을 물어봄. 자리 번호를 누르면 리바인 횟수 수정
- 탈락 버튼: 게임 중 이름 있는 자리마다 "탈락" 버튼, 누르면 등수 자동(남은 인원 = 등수), 한 명 남으면 자동 1등
- 탈락 되돌리기: 탈락(또는 리바인) 처리와 확인 창이 끝나면 10초 동안 "되돌리기" 바. 누르면 등수·리바인·블라인드·레벨 시간을 누르기 전으로(타이머는 그대로 흘러감)
- 우승 마무리 창: 한 명 남아 자동 1등이 되면 1. 게임 종료 / 2. 결과 복사 / 3. 랭킹 저장 버튼이 있는 창. 한 것은 ✓ 표시
- 초기화 경고: 등수가 들어간 결과를 랭킹에 저장하지 않았거나 저장 뒤 고쳤으면, 초기화 전에 "랭킹에 저장하지 않았어요" 창(랭킹에 저장 / 그래도 초기화)
- 월간 랭킹 동점: 같은 순위로 표시하고, 게임 수가 적은 사람을 위에(그다음 1등 횟수가 많은 순)
- 월 단위 마감: 저장하는 기록은 그 게임 날짜의 달로 들어감. 지난달은 최종 순위만 보이고(게임 기록 숨김) 딜러 비밀번호로는 저장·수정·삭제가 막힘. 월말 밤 게임은 다음 날 낮 12시까지 저장 가능
- 랭킹 관리자 수정(관리자 비밀번호): 어느 달이든 이름 바꾸기·합치기(그 달 기록 전체, 띄어쓰기·대소문자 무시), 게임 기록 고치기(이름·등수·뽑기점수 → 총점 다시 계산)·지우기
- 비슷한 이름 제안: 기록표 이름 칸에서 나오면, 예전 기록에 비슷한 이름(성 뺀 이름·포함·한 글자 오타)이 있을 때 "혹시 김철수?" 버튼. 누르면 바뀜, "아니에요, 다른 사람"으로 닫기. 저장 확인 창에도 남은 것을 경고. 관리자 수정 화면에는 그 달 랭킹의 "합칠 후보"를 보여 줌
- 타이머 숫자: 좁은 숫자 글꼴(Oswald)로 크게, 긴 블라인드·1시간 넘는 시간은 폭에 맞게 자동 축소
- 블라인드 업 30초 전: 오른쪽 위에 "곧 300 / 600" 주황 표시
- 리바인 칸: 자리 번호 아래 항상 표시(없으면 점선 "리바인", 있으면 R1·R2), 누르면 횟수 ±
- 관전 링크: "플레이어와 공유"(딜러 비밀번호) → 4글자 코드·링크. 플레이어는 `#watch-코드`로 타이머·자리별 이름·미션·등수·리바인·총점을 실시간으로 봄(보기 전용)

## 여러 테이블 토너먼트 (`#tourney`)

일회성이며 월간 랭킹에 들어가지 않습니다.

- 블라인드 타이머 하나를 모든 테이블 폰이 함께 봄(서버 시각 기준). 타이머와 토너 세팅은 토너먼트를 만든 폰(방장)만 조작, "1번 테이블(이름) 일시정지" 같은 알림
- 방장 폰이 꺼졌거나 방장이 정리를 안 하면: "여러 테이블" 화면 맨 아래 **관리자** 메뉴(관리자 비밀번호, 딜러 비밀번호와 별도)에서 방장 맡기 · 강제 종료 · 삭제 · 끝났거나 지난 토너먼트 한 번에 정리
- 방장: "새 토너먼트 만들기" → 방장 이름 → 이 폰이 방장 + 1번 테이블 담당(그 이름이 1번 테이블 딜러)
- 딜러 초대: 맨 아래 "🔗 딜러 초대 링크"(`?t=토너먼트id#tourney`)를 단톡방에. 딜러가 링크(또는 목록의 "참가하기")로 들어오면 이름을 묻고 테이블을 자동으로 맡음: 방장이 그 이름을 딜러로 정해 둔 테이블 → 딜러 없는 테이블 순. 빈 테이블이 없으면 방장에게 + 테이블을 부탁하라고 안내. 동시에 들어와 같은 테이블을 고르면 다음 빈 테이블로 다시 시도. 이미 맡은 폰은 이름을 묻지 않고 내 테이블로
- 테이블 담당 폰: 맡은 테이블은 그 폰(과 방장)만 조작(서버도 검사, 폰마다 무작위 키, 서버에는 해시만). 다른 폰에서는 보기만. 담당 없는 테이블은 누구나 + "이 테이블 맡기". 방장은 "담당 풀기", 본인은 "내 테이블 정보 → 담당 놓기"
- 시작 전 방장 화면에 "담당 폰 n/N 테이블"(누가 어느 테이블을 맡았는지)
- 플로어(1명): 방장과 딜러가 모두 딜플이라 전체를 보기 어려울 때. 방장이 맨 아래 "🧑‍⚖️ 플로어 링크"(`?t=…&f=키`)를 만들어 플로어에게만 보냄(만든 뒤 [링크 복사]를 한 번 더 눌러야 폰에서 복사가 막히지 않음). 그 링크를 연 폰은 타이머·토너 세팅·모든 테이블(탈락·이동·깨기·파이널 자리 뽑기·담당 풀기)을 조작. 토너먼트 지우기·플로어 링크 바꾸기는 방장만. 새 링크를 만들면 예전 플로어 링크·폰은 권한이 없어짐. 플로어는 테이블을 맡지 않고 이름만 넣음
- 기존 "참가자 등록", "내 테이블 정보(딜러 선택)", "+ 테이블"은 그대로. 참가자 등록 → 시작 자리 뽑기(테이블마다 딜러는 4번 고정) → 토너먼트 시작
- 딜러가 탈락해도 계속 딜링: 그 폰이 계속 테이블을 조작하고, 4번 자리는 이름이 어둡게만 남음(앉히기 버튼 없음), 테이블 이름도 그대로
- 자동 이동 버튼은 사람이 많은 테이블을 조작할 수 있는 폰에만, 파이널 자리 뽑기는 방장 폰에서
- 자리마다 탈락 / 이동(빈자리 랜덤) / 리바인·이름 수정, 탈락은 언제든 되돌리기 가능(등수 자동 재계산)
- 리바인 기간 탈락은 리바인 또는 탈락 확정을 고름
- 남은 인원·테이블별 인원 표시, 2명 이상 차이 나면 이동 추천
- 파이널 테이블 인원(기본 8명)이 되면 타이머 정지 → 파이널 테이블 자리 랜덤 뽑기(4번 딜러 규칙 없음)
- 마지막 1명이 남으면 자동 우승, 최종 순위 복사
- 탈락: 리바인 기간에는 리바인/탈락 확정 선택, 그 뒤에는 확인 창 없이 바로 처리 + 10초 "되돌리기" 바
- 탈락 순서는 최근 1명만, "더 보기"로 전체. 탈락한 사람은 자리에 어둡게 남음(플레이 중은 선명)
- 방장 타이머 버튼은 화면에 바로 반영, 연타도 합쳐서 모두 반영. 직접 누른 폰에는 큰 공지 없음
- 작은 알림은 타이머·진행 변화와 내 테이블 일만 (다른 테이블 탈락은 "최근:" 줄에만)
- 테이블을 깬 폰은 그 테이블 딜러가 옮겨 간 테이블을, 파이널이 되면 모든 폰이 파이널 테이블을 보여줌
- 토너먼트 지우기는 방장의 토너 세팅 안에
- 이동 추천에 [자동 이동]: 딜러(4번)를 뺀 한 명을 적은 테이블 빈자리로, 받는 테이블 폰에 "새로 온 사람" 창
- 이 테이블 깨기: 남은 사람을 다른 테이블 빈자리로 고르게 랜덤 배정하고 테이블을 없앰
- 블라인드 업 때 모든 폰(기록표·여러 테이블·관전)에 3초 큰 공지
- 목록에 어제 만든 진행 중 토너먼트도 보임(자정 넘김)
- 토너 세팅(파이널 인원, 테이블당 자리, 블라인드, 레벨 시간)은 시작 전·일시정지 중에만 바꿈

## 화면 꺼짐 방지

- 가로 전체 화면 타이머가 떠 있는 동안(게임 전·일시정지 중 포함), 게임 진행 중, 여러 테이블 타이머가 도는 중에 켜짐
- 브라우저 기능(Wake Lock)을 먼저 쓰고, 없는 폰은 `vendor/NoSleep.min.js`(NoSleep.js 0.12.0, MIT)로 대신함. 이때는 화면을 한 번 눌러야 시작
- 가로 화면 오른쪽 아래에 켜짐 여부 표시

## 인터넷이 약할 때

- `sw.js`(서비스 워커): 한 번 연 폰은 인터넷이 끊겨도 화면이 열림. 인터넷이 되면 항상 새 버전을 받음(GitHub Pages 10분 캐시도 건너뜀)
- 새 버전 알림: 설치한 앱을 뒤에 켜 둔 채 다시 열면 옛 화면이 그대로라, 열 때마다(1분에 한 번까지, 켜 둔 동안 10분마다) 서버의 index.html과 비교해서 다르면 위에 "새 버전이 나왔어요 [지금 적용]"을 띄움. 누르면 새로 고침(기록표·여러 테이블 상태는 폰에 저장돼 있어 그대로)
- 일반 기록표·타이머는 끊겨도 계속 동작. 랭킹 저장·여러 테이블은 인터넷 필요

## 홈 화면 앱

- `manifest.webmanifest` + `icons/`: 홈 화면에 추가하면 주소창 없이 "나나덤" 앱처럼 열림
- 폰을 가로로 돌리면 블라인드와 남은 시간이 화면 전체에 크게 나오고, 오른쪽 아래 [⚙ 게임 설정] 버튼으로 오른쪽 패널을 열어 기록표·블라인드 구조·탭을 봄
- 카톡 등 앱 안 브라우저로 열면 크롬/사파리로 열기 안내를 띄움 (앱 안 브라우저는 주소창을 숨길 수 없고 저장 공간도 따로)

수정하려면 `index.html` 하나만 고치면 됩니다.

## 보류 중인 작업

- 없음
